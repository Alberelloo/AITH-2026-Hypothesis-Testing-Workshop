# Встреча 2. План теста

## О чём встреча

На встрече 1 мы решили, что новый чекаут стоит тестировать: решение по конверсии — против точки безубыточности 0.246 п.п. с α = 0.5, 105 тыс. пользователей (B — 21 тыс.), 14 дней. Теперь превращаем их в план теста: что рандомизируем, какой эффект ловим, сколько недель ждём, какие метрики за что отвечают и как сделать тест короче. Выход встречи — дизайн-док, с ним идём на встречу 3 (запуск и доверие к данным).

Кейс — чекаут из `data/checkout_ab.csv`: конверсия ≈ 70%, 7.5 тыс. пользователей в день, сплит 80/20, предпериод 28 дней для CUPED.

## Ключевые концепции

- **Единица рандомизации и единица анализа** — пользователь против заказа или показа; если они различаются (средний чек, CTR), нужен дельта-метод или линеаризация; если рандомизировать можно только крупнее — встреча 5.
- **Одна формула для N и MDE** — со сторонностью $s$ и границей $\mu_0$ как явными параметрами: $N = (z_{1-\alpha/s} + z_{1-\beta})^2 (\sigma_A^2/w_A + \sigma_B^2/w_B) / (\delta - \mu_0)^2$.
- **Решение против θ_BE** — α = 0.5 из финмодели значит «внедряем, если оценка выше BE»; против нуля это α ≈ 0.24. Для guardrail финмодели нет, поэтому там классическое α = 0.05.
- **Цена решений дизайна** — относительный MDE против абсолютного (×2), сплит 80/20 против 50/50 (×1.56), односторонняя альтернатива (−21%); длительность — в целых неделях.
- **Вид теста** — superiority с границей 0, non-inferiority и equivalence с допуском Δ, решение против порога безубыточности θ_BE из встречи 1; MDE ≠ Δ ≠ θ_BE.
- **Критерий под тип метрики** — одна таблица «тип → критерий → ловушка»; любой критерий проверяется A/A-симуляцией на своих данных; «n > 30» для выручки не гарантия.
- **χ² на согласие = SRM** — мост ко встрече 3.
- **Роли метрик и поправки** — качество данных → OEC → guardrail → диагностические; поправки по правилу запуска (Spotify): OEC без поправки, guardrail односторонне с мощностью $1 - \beta/(G+1)$, диагностические — по семейству. В кейсе β-поправка только у guardrail: мощность OEC 0.8 задана встречей 1. Поэтому общий промах правила ≤ 0.3, а не 0.2, и только если guardrail набрал 0.9.
- **Ускорение** — $N \propto \sigma^2$: стратификация (и почему стратифицированное сэмплирование без стратифицированного среднего даёт α ≈ 1%), CUPED ($1 - \rho^2$, несмещённость, CUPED ≈ регрессия), линеаризация (сама дисперсию не снижает), выбросы (свой порог в группах ломает тест, корректна винзоризация порогом предпериода).
