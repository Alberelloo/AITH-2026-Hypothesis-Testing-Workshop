# Чек-лист запуска A/B-теста

> Артефакт встречи 3. Заполняется на каждый тест: до старта, в первые 24–48 часов и перед анализом. Каждый пункт проверяем числом; порог и действие заданы заранее. Пункт «не прошёл» — тест не анализируем, пока причина не найдена.

**Тест:** ______ · **Соль:** ______ · **Плановый сплит:** ___/___ · **Старт:** ______ · **Ответственный:** ______

**Порог SRM один на все проверки:** $p < 0.001$ на каждую — накопительную, по часам, по дням, по срезу; поправок не вводим. k проверок дают хотя бы одну ложную тревогу с вероятностью ≤ k × 0.1%: за первые 48 ч — 4 накопительных пересчёта (п. 8) + 24 часовых проверки первых суток (п. 9) = 28 проверок → ≤ 2.8%; 50 проверок — ≤ 5%. При $p < 0.001$ тест не анализируем, пока причина не найдена.

## Пять типовых причин SRM — где искать

| Причина | Признак в данных |
| --- | --- |
| Баг назначения | Дефицит варианта в одном устройстве / версии приложения; контроль больше плана; группа в логе ≠ пересчитанный хеш |
| Ботфильтр после назначения | Со всеми строками сплит честный; доля ботов различается по группам |
| Потери телеметрии | Дефицит равномерный по срезам; другое распределение задержки событий в варианте; обрыв на окне пайплайна |
| Триггер / редирект в одной ветке | Дефицит в одном источнике (реклама, диплинки); лишняя задержка в варианте |
| Неверная дата старта / кэш | Дефицит только в первые дни; дальше сплит по плану |
