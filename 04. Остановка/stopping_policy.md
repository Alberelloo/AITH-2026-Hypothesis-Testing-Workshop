# Политика остановки теста: шаблон

> Заполняется **до запуска** и прикладывается к дизайн-доку. После старта правила не меняются. Если что-то меняется, это записывается в журнал отклонений, а результат получает статус «разведочный».
> Пример заполнения для кейса «Горящие предложения» есть в `practice.ipynb`, задание 6.

## 2. Расписание взглядов

| Поле | Значение |
| --- | --- |
| Кто и как часто смотрит дашборд | |
| Взгляды для решения по эффективности (дни или доли информации) | |
| Взгляды для futility | |
| Мониторинг guardrail (как часто, каким методом) | |
| Как считается доля информации $t$ | по факту: $(n_A + n_B) / (2N_{\max})$ |
| Что делаем при пропущенном или внеплановом взгляде | пересчитываем границы по фактическим долям; внеплановые взгляды записываем в журнал |

| Поле | Значение |
| --- | --- |

## 4. Границы futility

| Поле | Значение |
| --- | --- |
| Критерий | условная мощность $\mathrm{CP}(\theta) < \gamma$ |
| $\theta$ (эффект из плана / текущий тренд) и $\gamma$ | |
| Дни проверки | |
| Граница в $z$ на этих днях | |
| Binding или non-binding | |
| Ожидаемая экономия выборки при $H_0$ и потеря мощности при MDE | |

## 5. Минимальная и максимальная длительность

| Поле | Значение |
| --- | --- |
| Остановка за успех не раньше | день … (полный недельный цикл: будни и выходные) |
| Остановка за вред | в любой день |
| Новизна и первичность: как проверяем | эффект по непересекающимся когортам (недели прихода) перед решением |
| Максимум $N_{\max}$; что делаем, если граница не пройдена | |
| Продление за $N_{\max}$ | запрещено для GST; если всё же продлили — результат разведочный |

## 7. Отчёт о рано остановленном тесте

- [ ] День остановки, доля информации $t$, какая граница пройдена и с каким $z$.
- [ ] Эффект — повторным доверительным интервалом GST ($\hat\Delta \pm b_i\sqrt{V}$) или доверительной последовательностью mSPRT. Точечная оценка — только рядом с интервалом и с пометкой «завышена отбором ранней остановки».
- [ ] Эффект по когортам (недели прихода): поздние когорты против ранних.
- [ ] Guardrail на день остановки с указанием их мощности: «сигнала нет» ≠ «вреда нет».
- [ ] Все отклонения от плана (внеплановые взгляды, пропуски, продление) и статус результата: подтверждающий или разведочный.
- [ ] Что после раскатки: holdout или повторный тест для устойчивого эффекта.
